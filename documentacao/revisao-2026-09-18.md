# Revisão do sistema — 18/09/2026

## Disponibilidade

A API estava desligada. API e interface foram iniciadas, e a migration mensal pendente foi aplicada. As consultas autenticadas de catálogo, clientes, orçamentos, auditoria e geração de PDF retornaram HTTP 200. A interface responde em http://localhost:3001.

Foram preservados URLs, contratos HTTP, campos e enums persistidos, identificadores dos workspaces e chaves de rascunho. Pastas e arquivos exigidos por ferramentas, como `app`, `public`, `prisma/migrations`, `page.tsx` e `layout.tsx`, seguem suas convenções.

## Correções e duplicações

- Removidos quatro renderizadores de tabela PDF sem uso, funções antigas de duplicação da interface e importações não utilizadas.
- Unificada a conversão de itens salvos para cópia e atualização. Isso corrigiu a perda de materiais por componente e de vínculos dos recortes na duplicação.
- Normalizado o preço de material dos componentes para número na resposta da API.
- Unificadas a abertura de PDFs, a sanitização de nomes de arquivos e a codificação do cabeçalho HTTP para nomes com acentos ou caracteres Unicode.
- Unificadas verificações de projetos preenchidos e opções repetidas de serviços na interface.
- Corrigido o carregamento do `.env` nos comandos Prisma.
- Numeração mensal usa o fuso da empresa, `America/Manaus`, em vez do fuso do servidor.
- Adicionada a migration `20260921010000_reservar_sequencia_anual`, que reserva o contador anual legado no mês 0 e evita que janeiro herde sua sequência. Nenhum orçamento antigo foi renumerado.
- Corrigido aviso de compatibilidade CSS de alinhamento flex.

A busca por duplicação comparou corpos de funções e foi complementada pela revisão dos fluxos de orçamento, serialização e PDF. Expressões pequenas e estruturas de apresentação semelhantes podem continuar existindo quando representam responsabilidades distintas.

## Comandos

- `npm run dev`: inicia API e interface juntas.
- `npm run db:deploy`: aplica migrations existentes com o ambiente da raiz.
- `npm run check`: valida TypeScript e código local não utilizado.
- `npm test`: inclui todos os testes de fonte, inclusive numeração e PDF que antes não faziam parte desse comando.
- `npm run test:integration`: banco e API em schema temporário.
- `npm run test:e2e`: navegador em serviços e banco isolados.
- `npm run build`: compilação completa.

Os testes de interface e PDF foram atualizados para os recursos já solicitados: modo rápido principal, modais de acabamento, quantidade por peça, totais por projeto e cabeçalho somente na primeira página de cada seção.
