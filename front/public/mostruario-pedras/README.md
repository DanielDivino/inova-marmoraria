# Exemplos visuais de pedras

As cinco amostras desta pasta vieram das imagens de `back/uploads/materials/`: Alaska, Bege Arabesco,
Grey Claro, Grey Escuro e Nero Marquina. São exemplos para o mostruário e para o simulador, em WebP:
`nome.webp` (960 px, textura do simulador e foto da ficha) e `nome-480.webp` (cartões).

Elas não criam materiais no banco nem preços de venda. Quando um material com o mesmo nome já estiver
cadastrado e ativo, o cadastro real prevalece. O preço dos exemplos aparece como "sob consulta".
