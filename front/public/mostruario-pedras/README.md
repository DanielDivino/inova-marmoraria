# Exemplos visuais de pedras

As cinco amostras desta pasta foram copiadas das imagens já existentes em
`back/uploads/materials/`: Alaska, Bege Arabesco, Grey Claro, Grey Escuro e
Nero Marquina. São exemplos para o mostruário e para a simulação dos ambientes.

Elas não criam materiais no banco nem preços de venda. Quando um material com
o mesmo nome já estiver cadastrado, o cadastro real prevalece. Disponibilidade
e preço dos exemplos são apresentados como "sob consulta".
